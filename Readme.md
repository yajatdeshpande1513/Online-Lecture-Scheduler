Tech Stack

Frontend: React 19 + Vite, React Router, Axios

Backend: Node.js, Express 5, Mongoose (MongoDB)

Auth: JWT  + bcryptjs for password hashing

Setup

Backend

cd server
npm install
npm run seed(for creatin users)
npm run dev

Frontend

cd client
npm install
npm run dev
